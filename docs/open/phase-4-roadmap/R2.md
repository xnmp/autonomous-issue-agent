## Result and fixed scope

Extend the existing stopped activation transaction to publish eligible components and blocked target decisions with one epoch/original-plan receipt. Revalidate source scope and quiescence under existing barriers. Use current-state origins, not checkpoint certification. Retry the original plan from SQL only, retaining blockers and exact identities. Add a canonical BlockedReviewExecutionMigration variant under the active repository epoch. Discovery consults retained target decisions before initialization. Consumers distinguish blocked migration from missing/corrupt active authority.
