## Result and fixed scope

Apply the reviewed F1 contract to the independently PR-owned reply marker and current remote PR branch. Bind the reply and PR identity even when linked issue changes; preserve existing timestamp identity and operator guidance. Include issue-reply routing onto an existing PR. Keep current no-compatible-session deferral: do not consume the PR reply until its required session or supported handoff exists. A blank PR reply is a separate unpaid no-op consumption receipt, preserving existing no-session/no-launch behavior; session deferral applies only to a nonblank reply.

## Acceptance

- [x] Repeated or reordered PR replies cannot buy duplicate resumes or overwrite newer consumption.
- [x] PR #N and issue #N markers stay distinct; same-head relinking does not transfer consumption or grant allowance.
- [x] Reservation refusal, admitted crash, changed/closed PR and source corruption have explicit outcomes.
- [x] Composed restart test resumes the current PR branch once and preserves sibling review holds.
- [x] Absent or incompatible required PR session leaves the reply unconsumed; issue no-PR fresh-reply behavior remains unchanged.
- [x] Blank PR reply is consumed once with no paid call, no session prerequisite and no invented issue re-block effect.
