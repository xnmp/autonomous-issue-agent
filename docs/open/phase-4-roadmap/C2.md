## Result and fixed scope

Extend workflow_components constraints and typed aggregate encoding with an additive migration. Reuse the target workflow row/version and existing run/admission identities. Reserve checks every selected component binding and writes its bounded consumption delta/receipt in the same money transaction. Return application uses immutable run identity and ordered watermarks. Expose family-specific adapter methods, not arbitrary mutation callbacks.

## Acceptance

- [x] Two competing admissions cannot consume the same reply or exceed a selected allowance.
- [x] Budget refusal or transaction failure leaves no consumed reply, allowance debit or partial component mutation.
- [x] Duplicate results apply once; stale results settle money but preserve newer components.
- [x] Steward-only shell, old schema upgrade, malformed payload and missing activated component are handled explicitly; old binaries are fenced.
