# [Phase 4 S4] Switch all review admission boundaries to current state

Published: [#203](https://github.com/xnmp/autonomous-issue-agent/issues/203). Accepted locally in `d7ef565`; independently reviewed and full `make test` green.
Parent: [tracking epic #199](https://github.com/xnmp/autonomous-issue-agent/issues/199). Outcome gate: **0.5**.

**Blocked by:** [S3 · #202](https://github.com/xnmp/autonomous-issue-agent/issues/202)

## Result and fixed scope

Switch canonical read, preflight, paid reservation, process launch and generation advance together to the materialized authority. Remove online archive maintenance/certificate dependencies at every caller. Keep owner, revision, family binding, active receipt, budget and hold checks. Compatibility conversion is stopped and bounded; unconvertible prior components remain held with their data intact.

## Implementation locations

- `src/issue_agent/adapters/workflow_rows.py`
- `src/issue_agent/adapters/control_store.py`
- `src/issue_agent/adapters/review_execution_control.py`
- `src/issue_agent/adapters/review_workflow_control.py`

## Acceptance

- [x] Drive read -> preflight -> reserve -> launch -> return -> finalize against real control adapters, with existing generation/owner/spend refusal cases.
- [x] Expired old archive certificates and unrelated retained-history writes cannot block valid current-state admission.
- [x] Malformed current authority, stale component bindings, exhausted budgets and unresolved holds still block.
- [x] Held admission never prevents exact retry, money settlement or recovery of older open rounds; unsupported existing components never enter the new path.

## Removal obligation

Delete production calls to archive admission and preflight maintenance; no configuration toggle between two active authorities.

## Out of scope

No adjacent policy changes or new orchestration framework.
