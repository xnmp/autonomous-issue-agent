# [Phase 4 S1] Replace lifetime replay with a generation-local ordered reducer

Published: [#200](https://github.com/xnmp/autonomous-issue-agent/issues/200). Accepted locally in `a82119c`; no live activation.
Parent: [tracking epic #199](https://github.com/xnmp/autonomous-issue-agent/issues/199). Outcome gate: **0.5**.

**Blocked by:** None; first implementation task.

## Result and fixed scope

Implement the ADR 0016 pure state contract: committed current state, generation-local baseline/cutoff, monotonic allocation and bounded unresolved suffix. Preserve existing outcome/strike/pin/session/display rules. Fold in allocation order, advance only a contiguous finalized prefix, and start a carried generation from its current projection. Keep old-generation unfinished work recoverable but inapplicable to the new projection.

## Implementation locations

- `src/issue_agent/domain/review_execution.py`
- `tests/domain/test_review_execution.py`

## Acceptance

- [x] Compare incremental folding with the existing full ordered oracle over permutations of failures, productive resets, copied verdicts and sessionless results.
- [x] An earlier open gap plus later finalized outcomes neither loses a debit nor resurrects an old session when the gap completes.
- [x] Advancing generation with an open gap preserves the accepted projection and clears the session; late old-generation results cannot change it.
- [x] Malformed/future/foreign identities and conflicting duplicate outcomes refuse; pending capacity is bounded independently of lifetime rounds.

## Removal obligation

Replace the domain requirement for an ever-growing active generation-boundary tuple; retain old decoding only for explicit compatibility until S7.

## Out of scope

No adjacent policy changes or new orchestration framework.
