## Result and fixed scope

Move address_review onto the F3 repair methods and migrate review-retries as one typed review-timestamp/count state. Preserve _current_review_at distinct-reviewer filtering and existing issue-scoped allowance. A newer qualifying review timestamp selects a new allowance episode; a successful push alone never resets it. Validate current PR linkage and add supported import/shadow/reset behavior.

## Acceptance

- [x] Repeated repair for the same qualifying review timestamp stops at the existing ceiling; a newer qualifying review resets only that allowance, while a successful push does not.
- [x] Duplicate, reordered, stale-generation and restarted result delivery cannot renew or erase debt.
- [x] Relinking/ambiguous multiple-PR legacy evidence blocks instead of duplicating allowance.
- [x] Review execution and rejection allowances remain independent.

## Removal obligation

Remove runtime get_review_retry/set_review_retry/clear_review_retry file authority. Retire address_review session/model/resume file writes using F3 methods.
