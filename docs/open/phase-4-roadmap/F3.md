## Result and fixed scope

Move FIX_CI session, actual model, current PR branch and resume/fork count to the fixed PR repair component using existing admitted-run receipts. Preserve verified issue-to-PR handoff where supported, remote head branch authority and worktree identity checks. This establishes the narrow shared repair read/result methods subsequently reused by address-review, rebase and PR resume; do not switch those callers in this issue.

## Acceptance

- [x] A real FIX_CI flow selects current remote branch and compatible session/model; unsupported handoff refuses without a paid call.
- [x] Runtime change starts fresh; newer sessionless result clears the prior handle; late returns cannot restore it.
- [x] Crash between result and continuation commit replays once; admitted returns are distinguished from never-launched refusals.
- [x] Terminal cleanup versus closed-unmerged requeue preserves existing debt semantics; ambiguous legacy session provenance blocks import.

## Removal obligation

Remove FIX_CI runtime file session/model/branch/resume writes only; later repair callers are retired by their own issues.
